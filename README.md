![# Uiiverse](https://i.ibb.co/dMPvqk9/logo.png)

**A Pearl-based Miiverse clone with many themes.**


**REQUIREMENTS**

1. Web browser,

2. PNID with a Mii character,

3. Email Address,

4. Web browser good enough for modern websites.

So go to https://uiiverse.greentendo.cc/ and click sign up. Then click create an account, This will send you to https://uiiverse.greentendo.cc/signup, now put all the data in except for Mii imagur image URL. That's where you put your "https://r2-cdn.pretendo.cc/mii/1234567890/normal_face.png". So click Sign Up and then check everywhere in your email for the email sent to you and then use Uiiverse!
